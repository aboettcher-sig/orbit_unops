## AlphaEarth dataset

- **Satellite Embedding V1 — Earth Engine Data Catalog.** Asset ID
  `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`. Coverage 2017–2024 annual,
  10 m, 64 bands, multi-modal (Landsat, Sentinel-1, Sentinel-2,
  LiDAR, others). CC-BY 4.0.
  https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL
  *(verified live 2026-04-28)*

- **Brown, C.F. et al. (2025).** *AlphaEarth Foundations: An
  embedding field model for accurate and efficient global mapping
  from sparse label data.* arXiv:2507.22291.
  https://arxiv.org/abs/2507.22291
